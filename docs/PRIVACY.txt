SourceLens Studio 静态交互演示

用户主动选择的视频与图片只在当前浏览器页面内读取，用于播放、截帧、裁剪及分镜合成，不上传媒体，不连接 RDS、Supabase、COS 或真实分析服务，不接收 API Key 或数据库密码。
画面、脚本、生成视频和素材队列只暂存在本次页面内存，刷新或关闭后清空；没有浏览器持久保存、真实云端对象或跨设备分享。页面的云上传为模拟。
候选来源为预设演示记录，不构成真实匹配、原始出处或版权证明。视频转脚本使用分镜模板，不识别视频语义；生成视频为浏览器本地编码的关键帧推进与字幕，不是AI文生视频，没有配音或音轨。内置画面为本项目程序绘制，不包含第三方媒体。
视频上限180秒/200MiB/20帧；图片单份8MiB。页面CSP禁止网络连接，仅允许本地媒体对象播放。页面未集成统计脚本；托管平台可能按照其隐私政策记录IP、请求时间等访问日志。
